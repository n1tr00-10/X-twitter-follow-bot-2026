# Twitter Follow Bot

Automated Twitter follow bot with proxy rotation and OAuth 1.0 authentication.

## Features

- Follow multiple users automatically
- HTTP/HTTPS/SOCKS5 proxy support
- OAuth 1.0 authentication
- Error handling with proxy fallback

## Quick Start

```bash
git clone https://github.com/n1tr00-10/X-twitter-follow-bot-2026/tree/main
pip install requests requests-oauthlib
python follow.py
